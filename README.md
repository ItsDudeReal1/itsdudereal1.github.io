# QuickTask

Easy-to-use mobile & desktop todo app hosted for free on **GitHub Pages**.

## Open the App

**Live URL:** [https://itsdudereal1.github.io/](https://itsdudereal1.github.io/)

## Install on Your Phone (Optional)

QuickTask is configured as an offline-ready Progressive Web App (PWA):

- **Android (Chrome):** Open [https://itsdudereal1.github.io/](https://itsdudereal1.github.io/), tap the **⋮** menu, and choose **Add to Home screen** / **Install app**.
- **iPhone / iPad (Safari):** Open [https://itsdudereal1.github.io/](https://itsdudereal1.github.io/), tap **Share**, and choose **Add to Home Screen**.

## Automatic Free Updates

GitHub Pages is enabled on the `main` branch (`/`). Any changes committed or merged to `main` automatically deploy to [https://itsdudereal1.github.io/](https://itsdudereal1.github.io/) within ~30 seconds at zero cost.

## Run Locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
